# Campus Lost & Found Tracker

## Problem Statement

Students often lose belongings like wallets, ID cards, calculators, bottles, notebooks and other items on a college campus. At the time other students may find these items but don’t always know how to return them to the rightful owner.

The **Campus Lost & Found Tracker** is a beginner-level Python command-line project. It offers a way to record and search for lost and found items.

## Objectives

The project aims to:

1. Record information about lost items.

2. Record information about found items.

3. Display recorded lost items.

4. Display recorded found items.

5. Search for an item by its name.

6. Find matches between lost and found items.

7. Demonstrate Python programming and problem-solving concepts.

## Information Collected

For each item the program collects:

- Item name

- Location

- Date

- Description

## Main Features

The program provides the following options:

1. Report Lost Item

2. Report Found Item

3. View Lost Items

4. View Found Items

5. Search, for an Item

6. Find Possible Matches

7. Exit

## Programming Concepts Used

The project demonstrates:

- Variables

- Input and output

- Conditional statements

- `for` and `while` loops

- Functions

- Lists

- Linear search

- Nested loops

- programming

## Expected Outcome

The project provides a command-line system. It allows users to record, view, search and compare lost and found items while the program is running.

## Limitation

The version stores the information only while the program is running. Permanent storage and database functionality are not included in this beginner version.
